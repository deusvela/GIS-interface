Данная работа была выполнена по поручению задания для курсовой работы под названием "Разработка ГИС-интерфейса пользователя"
Стек: React, JS, Tailwind, vite, Яндекс.Карты API, библиотека генерации ID - uuid, а также библиотека для иконок lucideReact. 
Исходя из этого было разработано ТЗ, реализованы диаграмы прецедента и диаграммы активности для более полного понимания работы этого приложения. Также было предоставлено и описание данных диаграмм и создана таблица с входными и выходными данными. Приложение подрузамевает взамиодействие с внешними сервисами (например, сервис мониторинга, сервис геокодирования и т.п.).
